# Екатерина | SCANORA Bot

Telegram-ассистент для компании SCANORA.

## Деплой на Railway (пошагово):

1. Зайди на **railway.app** и зарегистрируйся через GitHub
2. Нажми **"New Project"** → **"Deploy from GitHub repo"**
3. Загрузи эти файлы в GitHub репозиторий (или используй Railway CLI)
4. Railway сам найдёт Procfile и запустит бота

## Файлы проекта:
- `bot.py` — основной код бота
- `requirements.txt` — зависимости
- `Procfile` — команда запуска для Railway
